<h1 align="center"> Electronics Retail Network API </h1>

Профессиональная B2B-платформа для управления иерархической сетью по продаже электроники. Система позволяет выстраивать цепочки поставок, отслеживать задолженности и управлять ассортиментом товаров.

<h2 align="center"> 🛠 Стек технологий </h2>
*   **Python 3.13** + **Poetry** (управление зависимостями)
*   **Django 6.0** + **Django Rest Framework** (API)
*   **PostgreSQL 16** (основная база данных)
*   **Docker** + **Docker Compose** (оркестрация контейнеров)
*   **Coverage** (анализ покрытия кода тестами)
*   **SimpleJWT** (безопасная авторизация по токенам)
*   **drf-yasg** (автоматическая документация Swagger/ReDoc)

<h2 align="center"> 🚀 Быстрый запуск</h2>

  1. **Клонируйте репозиторий:**

<h2 align="center"> 📖 Документация API</h2>

<h2 align="center">  📋 Основной функционал</h2>  

### Иерархическая модель сети  
- 3 уровня звеньев: Завод (0), Розничная сеть (1), Индивидуальный предприниматель (2).  
- Динамический расчет: Уровень иерархии вычисляется автоматически на основе цепочки поставщиков.  
- Целостность данных: Реализована жесткая валидация для защиты от циклической зависимости (петли иерархии) и указания самого себя в качестве поставщика.  

<h2 align="center"> 🔒Безопасность и API</h2>  

- Доступ: API доступно только активным сотрудникам (is_active=True).  
- Защита финансов: Поле "Задолженность перед поставщиком" защищено статусом read_only (обновление долга через API невозможно).  
- Умная фильтрация: Поиск по стране реализован с игнорированием регистра (iexact).

<h2 align="center">  📑Административная панель (Django Admin)</h2>  

- Прямые ссылки: В списке объектов реализована кликабельная HTML-ссылка на карточку поставщика.  
- Массовые действия (Actions): Кнопка обнуления задолженности для неограниченного количества выбранных объектов.  
- Служебная информация: Раздельное отображение личных данных и рабочих параметров сотрудников (должность, отдел, дата найма).  

<h2 align="center"> 🧪 Тестирование и Coverage</h2>  

- Проект покрыт автоматизированными тестами (APITestCase), проверяющими все критические узлы бизнес-логики:  
- Валидация: Тесты на запрет циклической иерархии и самопривязки.  
- Фильтрация: Тесты поиска по существующим и несуществующим странам (case-insensitive).  
- Безопасность: Проверка прав доступа (активный/неактивный сотрудник) и неизменяемости поля debt.  
- Админка: Тестирование функции обнуления задолженности (Admin Action).  
- CRUD: Полный цикл создания и изменения поставщиков с привязкой Many-to-Many продуктов.  
Запуск тестов и отчет о покрытии:  

  Запуск тестов с замером покрытия

       docker-compose exec web coverage run --source='.' manage.py test

  Просмотр отчета в консоли

      docker-compose exec web coverage report

  Генерация HTML-отчета

      docker-compose exec web coverage html
